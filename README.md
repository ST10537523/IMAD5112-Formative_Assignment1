## App Info

I created this app for my IMAD5112 assignment 1. The idea came from the 
assignment background where the friend, Cora struggles to stay socially connected 
during busy days. I figured it would be cool to build something that gives 
her quick and easy suggestions based on what time of the day it is.

The app is called ✨Social Sparks✨ because each suggestion is like a little 
spark that helps someone stay connected with the people they care about.

---

## How the app works

The app is very user-friendly:

1. You open the app and see an input box
2. You type in a time of day, for example "Morning" or "Dinner"
3. You tap on the "Get My Spark" button
4. The app reveals a social suggestion based on what you've typed
5. If you want to try again you just tap the "Reset" button and start again

These are all the times of day the app recognises:

| What you type | What the app suggests |
|--|--|
| Morning | Send a 'Good morning' text to a family member |
| Mid-Morning | Send a 'What are your plans for today?' text to a friend |
| Afternoon | Share a funny meme or Tik Tok with a friend |
| Snack Time | Send a 'thinking of you' message |
| Dinner | Call a friend or a relative for a 5 minute catch up |
| Night | Leave a heartfelt comment on a friends post before you head to bed |

## Choices of desgin 

When I was designing the app I wanted it to have personality, feel warm and friendly because 
the whole point behind the app is about connecting people together. So I chose a 
pastel-pink and warm colour scheme to complement that feeling.

I decided to keep the layout simple with just one screen, to avoid making
the user feel overwhelmed. The most important features are the text field 
and the suggestion that appears, so I made sure those stand out the most.

I also played around with emojis to the suggestions to make them feel more fun and less 
like a dull notification.

## GitHub Actions

I set up GitHub Actions so that every time I push new code to GitHub it 
automatically tries to build my app. This is really helpful as it 
checks if the app will work on other computers and not just on mine.

You can see the workflow file I created here:
`.github/workflows/build.yml`

If the build passes there will be a green tick in the Actions tab which 
means everything is working correctly.
